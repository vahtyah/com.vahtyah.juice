# VahTyah (juice)

Precompiled **DLL distribution** package. Source is maintained privately; this repo ships
only the built assemblies (`Editor/`, `Runtime/`) as a Unity UPM package.

Install via Unity Package Manager → Add package from git URL:
`https://github.com/vahtyah/com.vahtyah.juice.git`

## API Reference

This package ships as an obfuscated DLL. The full public API — signatures, summaries and usage
examples — is documented in [`Documentation~/API.md`](Documentation~/API.md), generated from the
public surface.
